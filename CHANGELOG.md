# Changelog

All notable changes to this project are documented here. Versions follow the

## [1] - 2026-11-07

### Added

- Open every new app window on its own workspace, right after the current one.
- Maximize new windows (optional).
- Switch to the neighbouring workspace when the last window on the current one
  closes (optional).
- Keep windows of the same app together (optional).
- Excluded apps list in the preferences.
